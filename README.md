# AquaDesign – Water Engineering

**Engineering Water. Designing Solutions.**

AquaDesign is a cross-platform engineering application for irrigation design and, over time, broader water infrastructure calculations.

The original Android Java application is retained for audit and formula comparison. The new Flutter implementation is being introduced alongside it.

## First release
- Drip irrigation design
- Sprinkler irrigation design
- Metric and imperial display
- Offline project storage
- Engineering calculation records and PDF reports

## Technology
Flutter, Dart, Riverpod, Drift/SQLite and the Dart PDF ecosystem.

## Local development
Install Flutter, then run:

    flutter pub get
    flutter analyze
    flutter test
    flutter run
